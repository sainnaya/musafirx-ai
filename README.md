# ✈️ MusafirX AI

> **Your AI-powered travel companion for smarter, easier, and more personalized travel planning.**

MusafirX AI is a modern **AI-powered travel planning platform** designed to help travelers discover destinations, plan trips, explore communities, and get personalized travel recommendations.

The platform combines **Artificial Intelligence, modern web technologies, and an intuitive responsive interface** to create a seamless travel-planning experience.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/sainnaya/musafirx-ai.git
```

### 2. Navigate to the Project

```bash
cd musafirx-ai
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the root directory:

```env
VITE_GEMINI_API_KEY=your_gemini_api_key
```

Replace `your_gemini_api_key` with your Gemini API key.

### 5. Start the Development Server

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:3000
```
